# مدير الاستثمار العقاري - النسخة المحدثة

نظام إدارة الاستثمار العقاري الحديث والمتطور، مكتوب بأحدث التقنيات مع واجهة مستخدم عصرية وتجربة مستخدم محسنة.

## ✨ المميزات الجديدة

### 🎨 واجهة مستخدم حديثة
- تصميم عصري ومتجاوب مع جميع الأجهزة
- دعم كامل للوضع المظلم والفاتح
- رسوم بيانية تفاعلية باستخدام Chart.js
- إشعارات ذكية ومؤثرات بصرية جذابة

### 🚀 تقنيات حديثة
- **Frontend**: TypeScript, ES6+ Modules, Vite
- **Backend**: Flask مع SQLAlchemy محسن
- **Database**: PostgreSQL مع دعم JSONB
- **PWA**: تطبيق ويب تقدمي مع دعم العمل بدون إنترنت

### 📊 إدارة شاملة
- **العملاء**: إدارة كاملة لبيانات العملاء
- **الوحدات**: تتبع الوحدات العقارية وحالاتها
- **العقود**: إدارة العقود والأقساط
- **الشركاء**: إدارة الشركاء والمجموعات
- **الخزائن**: تتبع الأموال والتحويلات
- **التقارير**: تقارير تفصيلية ورسوم بيانية

### 🔧 ميزات تقنية متقدمة
- معالجة أخطاء شاملة ومتقدمة
- تحسين الأداء مع lazy loading
- دعم العمل بدون إنترنت
- تحديثات تلقائية للبيانات
- نظام إشعارات ذكي
- دعم الطباعة والتصدير

## 🛠️ التثبيت والتشغيل

### المتطلبات
- Node.js 18+ 
- Python 3.9+
- PostgreSQL 12+

### 1. تثبيت Frontend
```bash
# تثبيت التبعيات
npm install

# تشغيل في وضع التطوير
npm run dev

# بناء للإنتاج
npm run build
```

### 2. تثبيت Backend
```bash
cd backend

# إنشاء بيئة افتراضية
python -m venv venv

# تفعيل البيئة الافتراضية
# Windows
venv\Scripts\activate
# Linux/Mac
source venv/bin/activate

# تثبيت التبعيات
pip install -r requirements.txt

# تشغيل الخادم
python server.py
```

### 3. إعداد قاعدة البيانات
```bash
# تهيئة قاعدة البيانات
flask init-db

# تشغيل الترحيلات
flask migrate
```

## 🔧 التخصيص

### تغيير الألوان
```css
:root {
  --primary-color: #your-color;
  --secondary-color: #your-color;
}
```

### إضافة ميزات جديدة
1. أضف النوع في `src/types/index.ts`
2. أنشئ المكون في `src/components/`
3. أضف الخدمة في `src/services/`
4. حدث الواجهة في `src/app.ts`

## 🚀 النشر

### Render.com
```yaml
# render.yaml
services:
  - type: web
    name: estate-manager
    env: python
    buildCommand: pip install -r backend/requirements.txt
    startCommand: cd backend && python server.py
```

### Docker
```dockerfile
FROM node:18-alpine
WORKDIR /app
COPY package*.json ./
RUN npm install
COPY . .
RUN npm run build
EXPOSE 3000
CMD ["npm", "start"]
```
