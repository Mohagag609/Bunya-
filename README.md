## 🚀 **التشغيل السريع**

### 1. التشغيل المحلي
```bash
# تثبيت التبعيات
pip install -r backend/requirements.txt

# تشغيل الخادم
python backend/server.py
```

### 2. التشغيل مع Docker
```bash
# تشغيل كامل
docker-compose up -d

# أو تشغيل التطبيق فقط
docker build -t estate-manager .
docker run -p 8000:8000 estate-manager
```

### 3. فتح المتصفح
```
http://localhost:8000
```

### اختصارات لوحة المفاتيح
- `Ctrl + K`: فتح البحث الذكي

- `Ctrl + Y`: تقدم
- `Escape`: إغلاق النوافذ المنبثقة

### البحث المتقدم
- **البحث بالعبارة**: `"عبارة محددة"`
