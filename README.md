# برنامج إدارة الاستثمار العقاري (إصدار الخادم)

هذا هو برنامج لإدارة الاستثمارات العقارية. تم تحديث هذا الإصدار ليعمل ببنية الخادم والعميل (client-server)، حيث يتم تشغيل الواجهة الخلفية (backend) باستخدام Python/Flask وقاعدة بيانات PostgreSQL، مما يسمح بتخزين البيانات بشكل دائم وآمن على خادم بدلاً من متصفح الويب.

## المتطلبات الأساسية

- **Python 3.8+** و `pip`
- **PostgreSQL:** قاعدة بيانات PostgreSQL قيد التشغيل. أسهل طريقة لإعدادها محليًا هي باستخدام [Docker](https://www.docker.com/).
- **Git:** لإدارة إصدارات الكود.

## إعداد الواجهة الخلفية (Backend)

1.  **إنشاء بيئة افتراضية:**
    من المستحسن دائمًا استخدام بيئة افتراضية لمشاريع Python. من داخل مجلد المشروع الرئيسي، قم بتشغيل:
    ```bash
    python -m venv venv
    source venv/bin/activate  # On Windows use `venv\Scripts\activate`
    ```

2.  **تثبيت المتطلبات:**
    قم بتثبيت جميع الحزم اللازمة من ملف المتطلبات.
    ```bash
    pip install -r backend/requirements.txt
    ```

3.  **إعداد قاعدة البيانات:**
    أ. **إنشاء قاعدة بيانات:** قم بإنشاء قاعدة بيانات جديدة في PostgreSQL. يمكنك تسميتها `estate_pro_db`.

    ب. **إعداد متغيرات البيئة:** يحتاج الخادم إلى معرفة كيفية الاتصال بقاعدة البيانات. قم بتعيين متغير بيئة `DATABASE_URL`.

    على سبيل المثال (استبدل `user`, `password`, `host`, `port` بالقيم الصحيحة):
    ```bash
    # On Linux/macOS
    export DATABASE_URL="postgresql://user:password@host:port/estate_pro_db"

    # On Windows (Command Prompt)
    set DATABASE_URL="postgresql://user:password@host:port/estate_pro_db"
    ```
    إذا لم يتم تعيين هذا المتغير، سيحاول الخادم استخدام قيمة افتراضية مخصصة للتطوير المحلي.

    ج. **تهيئة الجداول:** قم بإنشاء جميع جداول قاعدة البيانات بناءً على النماذج المحددة في الكود.
    ```bash
    flask --app backend/server:app init-db
    ```
    يجب أن ترى رسالة "Initialized the database and created all tables."

## تشغيل التطبيق

1.  **تشغيل خادم الواجهة الخلفية:**
    من المجلد الرئيسي للمشروع، قم بتشغيل الأمر التالي:
    ```bash
    flask --app backend/server:app run
    ```
    سيتم تشغيل الخادم على `http://localhost:8000`.

2.  **الوصول إلى التطبيق:**
    افتح متصفح الويب الخاص بك وانتقل إلى `http://localhost:8000`. يجب أن ترى واجهة التطبيق تعمل الآن، مع تخزين البيانات على الخادم.

## ترحيل البيانات القديمة (لمرة واحدة)

إذا كان لديك بيانات مخزنة في الإصدار القديم من التطبيق (في IndexedDB بالمتصفح)، يمكنك ترحيلها إلى قاعدة البيانات الجديدة باتباع الخطوات التالية:

1.  **تصدير البيانات من المتصفح:**
    أ. **هام:** قبل تشغيل الخادم الجديد، تأكد من أن لديك نسخة من الكود القديم.
    ب. افتح ملف `export.html` في المتصفح الذي يحتوي على بياناتك القديمة.
    ج. اضغط على زر "بدء تصدير البيانات القديمة". سيتم تنزيل ملف باسم `database-export.json`.

2.  **استيراد البيانات إلى قاعدة البيانات الجديدة:**
    أ. تأكد من أن الخادم متوقف وأنك قمت بالفعل بتهيئة قاعدة البيانات (`flask init-db`).
    ب. من المجلد الرئيسي للمشروع، قم بتشغيل الأمر التالي، مع استبدال `database-export.json` بالمسار الصحيح للملف الذي قمت بتنزيله:
    ```bash
    flask --app backend/server:app import-json database-export.json
    ```
    ج. سيقوم السكربت بقراءة الملف وإدخال جميع البيانات الجديدة في قاعدة بيانات PostgreSQL.

بعد اكتمال هذه الخطوات، يمكنك تشغيل الخادم مرة أخرى (`flask run`) وستجد جميع بياناتك القديمة في التطبيق.
