- **CSV**: استيراد في برامج أخرى
- **JSON**: تبادل البيانات

## 🚀 **طرق التشغيل**

### 1. التشغيل المحلي العادي
```bash
# تثبيت التبعيات
pip install -r backend/requirements.txt

# تشغيل الخادم
python backend/server.py
```

### 2. التشغيل المحسن (مستحسن)
```bash
# تشغيل مع جميع التحسينات
./run_optimized.sh
```

### 3. التشغيل باستخدام Docker
```bash
# تشغيل كامل مع قاعدة البيانات
docker-compose up -d

# تشغيل التطبيق فقط
docker build -t estate-manager .
docker run -p 8000:8000 estate-manager
```

## 🚀 **البدء السريع**

### 1. تثبيت التبعيات
```bash

```

### 2. إعداد قاعدة البيانات
