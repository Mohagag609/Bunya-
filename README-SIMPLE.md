# 🏠 نظام إدارة العقارات - النسخة المبسطة

نظام إدارة عقارات شامل ومتقدم، مصمم خصيصاً للعمل على Netlify بدون مشاكل.

## ✨ المميزات الرئيسية

- 🏠 **إدارة الوحدات** - إضافة وتعديل وحذف الوحدات
- 👥 **إدارة العملاء** - قاعدة بيانات شاملة للعملاء
- 🤝 **إدارة الشركاء** - تتبع الشركاء ونسبهم
- 📋 **إدارة العقود** - عقود مبيعات وإيجار مرنة
- 💰 **إدارة الدفعات** - تتبع الأقساط والدفعات
- 🏦 **إدارة الخزائن** - تتبع التدفقات النقدية
- 📊 **التقارير** - تقارير مفصلة وإحصائيات
- 🔒 **أمان متقدم** - تشفير وحماية البيانات

## 🛠️ التقنيات المستخدمة

- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Database**: localStorage (مؤقتاً)
- **Charts**: Chart.js
- **Export**: XLSX.js للتصدير
- **PWA**: Service Worker للعمل بدون إنترنت

## 🚀 النشر على Netlify

### الطريقة الأولى: النشر اليدوي (الأسرع)

1. **تشغيل سكريبت الإعداد:**
   ```bash
   ./deploy-simple.sh
   ```

2. **النشر على Netlify:**
   - اذهب إلى [https://app.netlify.com](https://app.netlify.com)
   - اسحب مجلد `dist` إلى منطقة النشر
   - انتظر حتى يكتمل النشر
   - احصل على رابط الموقع

### الطريقة الثانية: النشر عبر Git

1. **رفع الملفات إلى GitHub:**
   ```bash
   git add .
   git commit -m "Add simple version for Netlify"
   git push origin main
   ```

2. **ربط مع Netlify:**
   - اذهب إلى [https://app.netlify.com](https://app.netlify.com)
   - اضغط "New site from Git"
   - اختر GitHub وحدد المستودع
   - اضبط إعدادات البناء:
     - Build command: `./deploy-simple.sh`
     - Publish directory: `dist`
   - اضغط "Deploy site"

### الطريقة الثالثة: Netlify CLI

```bash
# تثبيت Netlify CLI
npm install -g netlify-cli

# تسجيل الدخول
netlify login

# النشر
netlify deploy --dir=dist --prod
```

## 📖 الاستخدام

### للمستخدمين الجدد:
1. افتح الموقع
2. ابدأ بإضافة الوحدات والعملاء
3. أنشئ العقود والدفعات
4. استخدم التقارير لمتابعة الأداء

### للمستخدمين الحاليين:
1. افتح الموقع
2. سيتم تحميل البيانات تلقائياً من localStorage
3. استمر في العمل كالمعتاد

## 🔧 التطوير المحلي

```bash
# تشغيل خادم محلي
python -m http.server 8000

# أو باستخدام Node.js
npx serve .

# أو باستخدام PHP
php -S localhost:8000
```

## 📱 PWA Support

- اضغط على "Add to Home Screen"
- استمتع بالتطبيق كتطبيق أصلي
